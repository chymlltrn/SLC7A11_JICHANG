# 数据与代码可用性 / Data and code availability

## 中文

与已恢复的单细胞图对应的分析及可视化代码已公开于 GitHub：[SLC7A11_JICHANG](https://github.com/chymlltrn/SLC7A11_JICHANG)。目前已恢复的图级 Source data 保存在 [SLC7A11_JICHANG_SourceData](https://github.com/chymlltrn/SLC7A11_JICHANG_SourceData) 私有资料库中，计划于后续阶段公开；在此之前，编辑和审稿人可通过通讯作者申请授权访问。各子图说明记录了材料来源、覆盖范围及尚未解决的数据缺项。

## English — manuscript wording

Analysis and visualization code associated with the recovered single-cell figure panels is publicly available in the GitHub repository [SLC7A11_JICHANG](https://github.com/chymlltrn/SLC7A11_JICHANG). The currently recovered plot-level source data are retained in the private [SLC7A11_JICHANG_SourceData](https://github.com/chymlltrn/SLC7A11_JICHANG_SourceData) repository and will be made public at a later stage. Until then, authorized access for editors and reviewers can be arranged through the corresponding author. Panel-level documentation records the provenance and coverage of the available materials, including unresolved source-data gaps.
